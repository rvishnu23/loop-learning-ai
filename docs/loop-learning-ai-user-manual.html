1. Product Overview

Loop Learning AI is a two-sided learning workspace for teachers and students. It keeps formative diagnosis, personal practice, and official assessment separate while connecting them through a repeatable improvement loop.

For teachers

Create classes, subjects, and student logins; generate and review diagnostic quizzes; run live assessments; inspect class and student learning patterns; and use AI-assisted marking for uploaded official answer sheets.

For students

Join a teacher's live quiz, receive topic-level learning status, practise a weak topic privately, upload study material, and ask the Personal AI Tutor for explanations and worked guidance.

The learning loop: Assess with a diagnostic quiz, analyse topic-level results, improve through targeted practice and tutoring, then reassess to see whether the learning signal changes.

2. Quick Start and Demo

First-time setup

  1. Install a current Node.js version.
  2. Run npm install, then npm run dev.
  3. Configure Supabase and the AI key using the environment variables in the Deployment section.
  4. Open the Vite URL shown in the terminal.

Built-in demo workspace

The application seeds demo data when the demo teacher account is present. Use the role switcher on the login screen.

3. Teacher Manual

3.1 Account and navigation

  1. Select Teacher on the authentication screen.
  2. Create an account with a name, username, and password, or log in to an existing account.
  3. Use the teacher sidebar to open Dashboard, Assessment, Classes & Students, Subjects, Create AI Quiz, Live Quizzes, Previous Assessments, Classroom Learning Analysis, Student Profiles, and Settings.
  4. Use Account to change the password and Log out to end the session.

3.2 Set up the class workspace

  1. Open Classes & Students and create a class using class name, section, and academic year.
  2. Select the class chip and add each student's name and roll number.
  3. Use search to find students. Edit or delete records as needed.
  4. Choose Set Login for a student, create a username and password, and share the credentials securely. A saved password is not shown again.
  5. Use Enable/Disable to control whether a student can log in.
  6. Open Subjects and add the curriculum subjects used by the class.

3.3 Read the Dashboard

The Dashboard combines student count, assessment count, class averages, recent assessments, performance charts, and the recommended teaching move. The recommended move is driven by the weakest observed topic and links directly to Classroom Learning Analysis.

3.4 Create and approve an AI diagnostic quiz

  1. Open Create AI Quiz and choose a class and subject.
  2. Enter a chapter and list topics one per line.
  3. Select one or more question types: MCQ, True/False, Fill in the Blanks, Short Answer, 2 Mark, 3 Mark, or 6 Mark.
  4. Set question count, difficulty, duration, and optional teacher instructions. Generation supports up to 12 questions.
  5. Select Generate Quiz. The AI returns tagged questions, answers, explanations, difficulty, and marking data.
  6. Review every item. Edit wording, marks, topics, answers, and model answers; regenerate one item, regenerate the entire quiz, delete an item, or add another generated item.
  7. Select Save Draft to keep the quiz private, or Approve & Start Quiz to create a unique join code and make it live.
Teacher control: AI is used for drafting, not autonomous publishing. The teacher review screen is the approval gate before students see a diagnostic quiz.

3.5 Run a live quiz

  1. Share the generated quiz code with students in the same class.
  2. Open Live Quizzes to monitor joined, attending, completed, and not-joined students. The view refreshes automatically.
  3. Scores and answers remain hidden while the quiz is live.
  4. Close the quiz when the session ends. The result view then exposes topic analysis and individual attempts.
  5. Use Reassess (Relaunch) to issue a fresh code for the same quiz, or Edit / Reuse to adjust future attempts.

3.6 Interpret diagnostic results

Each topic is classified using configurable thresholds:

StatusDefault ruleMeaning
Strong80% or higherEvidence of secure performance in the current diagnostic.
Needs Practice50% to 79%Topic should receive more practice or explanation.
PriorityBelow 50%Highest-need topic for targeted support.

Classroom Learning Analysis shows students struggling by topic, class status, an AI-generated insight, and a bar chart. Student Profiles show subject averages, topic profile, and improvement trends across diagnostics.

4. Student Manual

4.1 Student login

  1. Select Student on the authentication screen.
  2. Enter the username and password supplied by the teacher.
  3. If the account is disabled or credentials fail, contact the teacher. Students do not create their own accounts.

4.2 Join a live diagnostic quiz

  1. Open Join Live Quiz and enter the code shared by the teacher.
  2. Confirm the subject, chapter, duration, and diagnostic status, then select Start Quiz.
  3. Answer MCQ, True/False, Fill in the Blanks, and written questions. Use the question navigator to move between items.
  4. The timer counts down from the assessment duration. Answers are persisted while navigating. Submission is available at any point and the quiz auto-submits when time reaches zero.
  5. After submission, view the overall score, topic learning profile, status categories, explanations, and the recommended next practice topic.

4.3 Use Personal Practice

  1. Open Personal Practice. Weak topics from diagnostic results appear as recommendations.
  2. Choose a subject, optionally add a chapter, enter a topic, select question types, set questions per type, and choose difficulty.
  3. Generate a private practice quiz. The limit is 8 total questions for reliable generation.
  4. Answer every question and submit. Objective answers are graded immediately; written answers receive AI feedback when available.
  5. Review solution steps, what was correct, what was missing, the misunderstood concept, and the next practice suggestion. Recent practice history remains private to the student.

4.4 Use the Personal AI Tutor

  1. Open Personal AI Tutor, select a subject, and optionally set a topic.
  2. Ask a free-form question or use a quick action such as explain, simplify, give an example, test me, explain a mistake, revise, summarise, use a diagram, use a graph, or explain step-by-step.
  3. Upload PDF or image study material. The tutor can use the material as context and keeps the material attached to the student's workspace.
  4. Review the response, which can include structured steps, tables, graphs, and diagrams where useful.
Learning privacy: Personal Practice and Personal AI Tutor activity is scoped to the logged-in student. Diagnostic and published official results are presented separately so practice does not become an official grade.

4.5 View performance and official results

My Performance shows diagnostic performance by subject, topic status, and improvement trend. Teacher-verified official results appear in a separate Official Assessment Results section and include marks, maximum marks, and percentage.

5. Official Assessment Workflow

This workflow is separate from the diagnostic quiz system. It supports a real question paper, answer key, optional reference material, and individual student answer sheets.

Create assessment→Upload materials→AI evaluation→Teacher verification→Publish→Analytics

5.1 Create

Open Assessment, choose New Assessment, and enter the assessment name, class, subject, optional chapter/topic, and maximum marks.

5.2 Upload

Upload the required question paper and answer key. Reference material is optional. Then upload an answer sheet against each student. PDF, JPG, JPEG, and PNG files are supported; PDF and image files are the AI-readable formats.

5.3 Evaluate with AI

Run an evaluation per student or run all. The AI compares the question paper, answer key, reference material, and answer sheet and proposes question-wise marks, answer summaries, feedback, possible learning difficulty, and overall feedback.

5.4 Verify and publish

Open each evaluated student. Accept all AI marks or edit final marks question by question, add teacher comments, and select Verify & Publish. If a file cannot be read, enter the total manually. A result is not official until the teacher publishes it.

5.5 Analytics

Analytics reports class average, highest and lowest percentage, number published, topic-wise performance, and individual verified results. Published results are visible to the corresponding student in My Performance.

Important: AI evaluation is an initial suggestion. Human verification is a required product control for official assessment results.

6. AI Behaviour and Safeguards

  • Diagnostic generation: creates JSON-structured questions with type, marks, topic, difficulty, answer data, explanations, and (for written items) model answer and marking points.
  • Question regeneration: regenerates one question or the whole quiz while preserving the teacher's selected scope.
  • Subjective grading: awards partial credit against model answers and marking points and returns concise learning feedback.
  • Practice generation: creates a private quiz from the student's selected subject, chapter, topic, difficulty, and question mix.
  • Doubt solving: answers in a tutor voice, prioritises uploaded study material, and can produce text-based visual structures.
  • Answer-sheet evaluation: reads supported uploaded documents and returns a teacher-reviewable initial evaluation.
  • Validation: generated diagnostic questions are parsed and checked for expected count, required fields, MCQ structure, and subjective marking fields.
  • Fallback: the server retries transient Gemini failures and can use a configured fallback model.

AI responses should be treated as learning assistance and review input. Teachers remain responsible for content accuracy, marks, and official publication.

9. Configuration and Deployment

Required environment variables

VariablePurpose
SUPABASE_URLSupabase project URL used by the server handlers.
SUPABASE_SERVICE_ROLE_KEYServer-side key used for REST reads and writes. Keep private.
GEMINI_API_KEYServer-side Google Gemini API key. Keep private.
GEMINI_MODELOptional model override; defaults to the model requested by the client.
GEMINI_FALLBACK_MODELOptional fallback model for transient/provider failures.

Supabase setup

  1. Create a Supabase project.
  2. Run the SQL in supabase-schema.sql.
  3. Provide the project URL and service-role key to the server environment only.
  4. Do not expose the service-role key in client-side Vite variables.

Build and deploy checks

  1. Run npm run build to create the Vite production bundle.
  2. Deploy the frontend and API handlers to a host that supports the project routing model, such as a Vercel-style deployment.
  3. Add environment variables in the host project settings.
  4. Open the deployed site, create a test account, verify database persistence, then test one AI request.
Operational security: This is a hackathon prototype. The current UI performs application-level credential checks and the server uses a service-role database key. A production release should move authentication and authorization to a dedicated server-side identity system, add row-level ownership checks, validate file size/type, and protect AI endpoints with authenticated sessions and rate limits.

10. Prototype Boundaries and Roadmap

Current boundaries

  • Diagnostic and practice generation depends on a configured Gemini key and an available model.
  • AI-readable official assessment files are PDF or image formats; unsupported uploads require manual verification.
  • The prototype stores application state as JSONB rather than normalized, multi-tenant domain tables.
  • Passwords are salted and hashed in the application, but this is explicitly not a replacement for production authentication.
  • Official results require teacher publication and are intentionally separated from diagnostics and practice.

Strong next steps

  • Replace prototype authentication with Supabase Auth or another server-managed identity provider.
  • Add tenant-aware authorization, audit logs, rate limiting, and signed/private file access.
  • Move large files to object storage and store metadata in normalized tables.
  • Add exportable reports, attendance/session controls, and richer longitudinal analytics.
  • Add automated tests for quiz grading, threshold classification, role access, and official publication rules.

Hackathon value proposition

Loop Learning AI closes the gap between knowing a student's score and knowing what to do next. It combines structured diagnosis, explainable topic signals, targeted practice, AI tutoring, and a human-controlled official marking workflow in one coherent learning loop.
